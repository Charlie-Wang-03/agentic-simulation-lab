# Support

Use GitHub Discussions or a public issue for installation questions, documentation gaps, and reproducible non-security defects after the repository is published. Search existing material first.

Do not post proprietary solver files, license data, tokens, private paths, hostnames, or confidential models. Security concerns belong in GitHub private vulnerability reporting as described in [SECURITY.md](SECURITY.md). Ansys product support is outside this independent project's scope; use the support channel allowed by your Ansys license.
