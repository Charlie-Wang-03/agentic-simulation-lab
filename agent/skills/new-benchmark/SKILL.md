# New benchmark

## When to use

Use only when a new benchmark is explicitly in scope.

## Preconditions

Choose a canonical, low-cost problem with defensible physics and a supported API.

## Main commands

Reuse the domain common layer; add setup, extraction, explicit validation, and one
manifest schema v2 record with authoritative `result_file`. Start at `NOT_RUN`,
rebuild the catalog, update paired tutorials, and run the project audit.

## Evidence source

Canonical Case Result Contract v1 plus analytical/conservation/canonical checks.

## Stop conditions

Stop on unavailable capability/license, ambiguous validation, unsafe executable,
or inability to produce a single authoritative result.

## Forbidden shortcuts

Do not copy vendor examples, add an agent framework, commit generated solver data,
or mark PASS without a fresh authorized solve and passing physics checks.

## Expected output

Discoverable manifest entry, project-relative evidence, normalized truthful status,
tests, tutorial pair, and passing static audit.
