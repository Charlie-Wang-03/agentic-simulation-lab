# Agent layer

This directory packages small, auditable procedures for agents operating the lab. Skills do not grant permission to launch solvers or change external systems; they define sequencing, evidence, and safety expectations.

The retained skills have non-overlapping responsibilities: catalog discovery,
layered solver diagnosis, authorized run orchestration, result/physics validation,
new-benchmark authoring, and project/public-candidate audit. Older one-step skills
were consolidated into these procedures so their stop conditions and evidence
authority cannot drift apart.
