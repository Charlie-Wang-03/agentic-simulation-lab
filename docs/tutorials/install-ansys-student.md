# Install Ansys Student on Windows

Use only the current official [Ansys Student download page](https://www.ansys.com/en-gb/home/academic/students/ansys-student). Read the current system requirements, problem-size limits, use restrictions, export controls, and installer clickwrap before downloading.

1. Confirm a supported Windows edition and hardware.
2. Back up unrelated work and follow the official page's guidance about existing Ansys installations.
3. Download, verify, extract, and run the official installer with the privileges it requests.
4. Accept terms only if the intended educational use complies.
5. Reboot if required; launch Workbench once through the normal Start-menu path.
6. In this project, install only the needed Python extra and run `agentic-sim doctor`.

Do not modify registry, licensing services, firewalls, environment variables, or product files to force discovery. Missing software, license, or Student functionality is `BLOCKED`.
