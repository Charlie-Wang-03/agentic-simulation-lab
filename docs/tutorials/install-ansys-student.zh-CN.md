# 在 Windows 安装 Ansys Student

只使用当前官方 [Ansys Student 下载页面](https://www.ansys.com/en-gb/home/academic/students/ansys-student)。下载前阅读最新系统要求、模型规模限制、使用限制、出口管制与安装 clickwrap。

1. 确认 Windows 版本和硬件受支持。
2. 备份无关工作，并遵循官方页面关于已有 Ansys 安装的说明。
3. 下载、校验、解压官方安装包，并按安装程序要求的权限运行。
4. 仅当教育用途符合条款时接受协议。
5. 如有要求则重启，并从正常开始菜单启动一次 Workbench。
6. 在本项目中只安装需要的 Python 可选依赖，再运行 `agentic-sim doctor`。

不要为了强制发现而修改注册表、许可证服务、防火墙、系统环境变量或产品文件。软件、许可证或 Student 功能缺失均应标记为 `BLOCKED`。
