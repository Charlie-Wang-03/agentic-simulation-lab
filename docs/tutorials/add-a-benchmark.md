# Tutorial 4: add a benchmark case

Place the script in the owning domain's `cases/` directory and reusable code in `common/`. Add one manifest record with a stable slug, entrypoint, role, normalized status, and evidence. Start at `NOT_RUN`; change it only after executing declared physical checks. Rebuild the catalog, run tests and Ruff, and run the public-tree audit. Do not commit generated solver artifacts.
